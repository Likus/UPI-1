# Плата консоли УПИ-1

Проект основной печатной платы в KiCad (создан в KiCad 10).

Файлы:

- `upi1-main-pcb.kicad_pro` — проект;
- `upi1-main-pcb.kicad_sch` — схема (U2 — CH32V003A4M6);
- `upi1-main-pcb.kicad_pcb` — трассированная плата.

Библиотеки встроены в файлы проекта — внешних зависимостей нет, достаточно
открыть `.kicad_pro` в KiCad 9/10.

## Производство

Gerber-файлы, сверловка и прочее не хранятся в репозитории — они воспроизводятся
экспортом из KiCad:

- Gerber: *Файл → Изготовить → Экспортировать Gerber…* (включая Edge_Cuts);
- сверловка: *Excellon* из того же диалога;
- BOM/позиционный файл: плагин *Export* / *Позиционные файлы*.

Опубликованные автором партии плат изготовлены по состоянию этого проекта.
