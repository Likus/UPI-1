# Корпус консоли УПИ-1

Три равноценно актуальные **конфигурации** корпуса (k = конфигурация):

| Конфигурация | Описание | Файл |
|---|---|---|
| **k1** | Девелоперская: со встроенным разъёмом программирования | `step/upi1-k1-console.step` |
| **k2** | Стандартная, без разъёма | `step/upi1-k2-console.step` |
| **k3** | Special edition — без логотипа на задней крышке (место под свой вариант) | `step/upi1-k3-console.step` |

В репозитории — STEP-экспорт полных сборок. STL для печати не включены:
экспортируйте нужные твёрдые тела из STEP любым CAD (FreeCAD: выделить тело →
*Export Mesh*). Например, крышка k3 без логотипа существует только в сборке
`upi1-k3-console.step`.

Кнопки и фиксаторы одинаковы во всех конфигурациях и извлекаются из той же
сборки.
